# 命名規範

## 正式名稱

中文正式名稱：智慧食材保存與膳食管理系統

英文正式名稱：Smart Pantry & Nutritionist

## 命名對照

- Repo：`smart-pantry-nutritionist`
- Backend service：`smartpantry-backend`
- Frontend service：`smartpantry-frontend`
- Database service：`smartpantry-db`
- PostgreSQL database：`smartpantry_db`
- PostgreSQL user：`smartpantry_user`
- FastAPI title：`Smart Pantry API`

## 規則

文件與 README 使用「智慧食材保存與膳食管理系統」或 `Smart Pantry & Nutritionist`。Python module、DB service、環境變數可使用 `smartpantry`。UI 主要顯示文字必須使用繁體中文。
